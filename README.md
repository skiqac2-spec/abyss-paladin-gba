# ABYSS PALADIN (GBA)

디아블로2에서 영감을 받아 게임보이 어드밴스용으로 "뭉개서" 만든 아이소메트릭 핵앤슬래시 팬 오마주입니다.
그래픽·몬스터·보스·지명은 모두 이 프로젝트를 위해 새로 만든 오리지널이며, 원작 에셋은 사용하지 않았습니다.

## 이번에 추가된 기술

| 기능 | 내용 |
|---|---|
| **3D 프리렌더 성기사** | `tools/paladin3d.py`가 오리지널 3D 성기사 모델을 아이소메트릭 카메라로 8방향 × 5동작(대기, 걷기 2, 휘두르기 준비, 베기) 렌더링합니다. 좌우 반전 없이 진짜 8방향이라 칼은 항상 오른손, 방패는 왼손에 있습니다. |
| **8×8 타일 중복 제거 + 스트리밍** | 40프레임(타일 640개) 중 겹치는 타일을 하나로 합쳐 266개만 저장하고, 매 프레임 현재 동작의 타일 16개만 VRAM에 복사합니다. |
| **스트리밍 BGM** | 오리지널 곡 3개(마을 / 던전 / 보스)를 13.4kHz 모노로 재생합니다. 마을 곡은 4비트 ADPCM으로 압축하고, 던전·보스 곡은 8비트 PCM입니다. VBlank 인터럽트가 DMA로 소리를 계속 흘려 보내고, 효과음(PSG)과 함께 울립니다. |
| **한글 대화창** | `tools/story_ko.txt` 대본에서 실제로 쓰인 글자만 뽑아(현재 317자) 2bpp 글꼴(갈무리11, SIL OFL)로 넣습니다. 반투명 대화창(알파 블렌딩) 위에 테두리 있는 글자가 한 글자씩 찍힙니다. A: 다음 / 빨리 넘기기, START: 장면 건너뛰기 |
| **스토리** | 액트마다 도입, 치유사 대화, 보스 등장·쓰러짐, 액트 마무리 장면이 있고 헬 난이도 액트 V를 깨면 엔딩이 나옵니다. 모두 이 프로젝트용 오리지널 이야기입니다. |

### 대사 고치기

`tools/story_ko.txt`를 메모장으로 열어 문장을 바꾸고 `make`를 다시 하면 됩니다. 줄바꿈과 페이지 나누기, 필요한 글자 추출은 자동입니다.

### 성기사 모델 고치기

`tools/paladin3d.py`를 고친 뒤 `make render` (1분 정도 걸림) → `make`.

## ROM 파일 (roms 폴더)

| 파일 | 내용 |
|---|---|
| `act1.gba` | 액트 I · 잿빛 황야 (새 게임은 여기서 시작) |
| `act2.gba` | 액트 II · 가라앉은 사구 |
| `act3.gba` | 액트 III · 늪지 정글 |
| `act4.gba` | 액트 IV · 불타는 계단 |
| `act5.gba` | 액트 V · 얼어붙은 왕관 |

각 액트 = 마을 + 던전 3층(마지막 층에 보스). 보스를 잡고 붉은 포탈에 들어가면 액트 클리어.

## 이어하기 (액트 → 액트, 노말 → 나이트메어 → 헬)

액트 클리어 화면에 **13자리 패스워드**가 나오고 자동 저장됩니다.
다음 액트 ROM을 켜서 `PASSWORD`에 입력하면 레벨·장비·스킬·물약·골드가 그대로 이어집니다.
액트 V를 클리어하면 다음 난이도(나이트메어 → 헬)로 다시 액트 I ROM부터 진행합니다.

패스워드 대신 세이브 파일을 복사해도 됩니다: 예) `act1.sav`를 복사해 `act2.sav`로 이름 변경 → act2 ROM에서 `CONTINUE`.

## 조작

| 버튼 | 기능 |
|---|---|
| 십자키 | 8방향 이동 (대각선 포함) |
| A | 기본 공격 / 마을 치유사와 대화 / 대화 넘기기 |
| B | 선택한 스킬 사용 |
| R | 스킬 전환 (강타 / 신성 화살 / 신성 해머) |
| L | 체력 물약 |
| SELECT | 마나 물약 |
| START | 캐릭터·스킬 창 (스킬 포인트 배분, 마을 귀환) / 대화 장면 건너뛰기 |

## 직접 빌드하기 (선택)

devkitARM(또는 `gcc-arm-none-eabi`)과 Python 3(numpy, Pillow)가 있으면:

```
make
```

결과물은 `out/act1.gba` ~ `out/act5.gba`.
